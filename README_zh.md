**把身体照顾好，把喜欢的生活过久一点。**

## 关于本仓库

本公开仓库存放由 GitHub Pages 发布的静态网页。源码项目和开发提交历史单独维护。如需在本地浏览，可在本仓库目录使用静态 HTTP 服务器，例如：

```sh
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/`。

本站提供一般健康信息，不构成医疗建议，也不承诺延寿效果。个人健康问题请咨询专业人士。
