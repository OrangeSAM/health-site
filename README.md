# Longevity · 长命百岁

**Take care of your body, and spend more time living the life you enjoy.**

[Visit health.yibi.host](https://health.yibi.host/) · [中文版](README_zh.md)

长命百岁 is a Chinese-language guide to everyday eating and exercise. It offers practical starting points, two handbooks, articles, examples, and printable templates, with sources and context for readers who want to explore further.

## About this repository

This public repository contains the generated static site published with GitHub Pages. The source project and its development history are maintained separately. To browse the site locally, serve this repository with any static HTTP server, for example:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

The site provides general health information, not medical advice. It does not promise a longer life; consult a qualified professional about individual medical needs.
